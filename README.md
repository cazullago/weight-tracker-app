# Weight Tracker 🔥

Android weight tracker for Samsung Galaxy S25 Ultra.

- Red high-energy app, white month calendar
- Tap any day square to type your weight in lbs — it shows right in that square
- Stats: latest weight, days logged, change since first entry, this month
- Recent entries list, tap to edit/delete
- Weights are saved on your phone only (SharedPreferences), no account, no cloud

Build: GitHub Actions `.github/workflows/build-apk.yml` builds a debug APK on push/tag.
Install: download the APK from the GitHub release, tap Install anyway on Play Protect if prompted.
App ID: com.weighttracker.weight_tracker — debug-signed test build, not a Play Store release.
